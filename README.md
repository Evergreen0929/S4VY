# S4VY: Segment Anything in Feed-Forward 4D Visual Geometry

[![Paper](https://img.shields.io/badge/arXiv-2609.36875-b31b1b.svg)](https://arxiv.org/abs/2609.36875)

**This is a research project from [NVIDIA Research](https://www.nvidia.com/en-us/research/).**

Jingdong Zhang, Xin Li, Jan Kautz, Wenping Wang, Chris Choy

## About

S4VY is a promptable instance segmentation model built on feed-forward 4D visual geometry.
It turns RGB observations into class-agnostic 4D instance masks, where each persistent object
query tracks one entity across every view, and grounds them in natural language through an
agentic system.
